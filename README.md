**6+ years** building and shipping production software across **frontend, backend, APIs, AI, and cloud**. I take products from idea to production: React and Next.js interfaces, Node.js and FastAPI services, Go where it fits, and LLM features that actually ship.

I care about reusable systems, clean API boundaries, reliable delivery, and software that stays fast under real load.

**Highlights**
- Cut feature rollout time by **~30%** with shared React + TypeScript patterns across onboarding, payments, and documents at Atlys
- Open-sourced [`virtualized-react`](https://github.com/yogthesharma/virtualized-react) targeting **sub-16ms** frame times on large lists
- Shipped **Zyvia** (AI-native task product) from zero to acquisition by ScreenStudio in 10 weeks
- Building **lcode** (Sitry): AI-native desktop editor with a FastAPI AI backend, WebSocket streaming, and a capability registry
- Building **Monorch**: TypeScript AI control plane for agents, graphs, workflows, MCP, and PostgreSQL adapters
- Built **Boson**: private alpha/beta program platform (Next.js, Fastify, PostgreSQL, Docker)
