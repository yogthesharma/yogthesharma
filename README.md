### About

Senior Software Engineer with **5+ years** shipping complex React / Next.js apps, component libraries, data-heavy dashboards, and performance-critical UIs.

Based in **Gurugram, India**. Currently a Full Stack Engineer at **Uniblox**, previously Senior Software Engineer at **Atlys**.

Highlights from recent work:
- Cut feature rollout time by **~30%** with reusable React + TypeScript systems across onboarding, payments, and documents
- Open-sourced [`virtualized-react`](https://github.com/yogthesharma/virtualized-react) targeting **sub-16ms** frame times on large lists
- Shipped **Zyvia**, an AI-native product acquired by ScreenStudio
- Building **lcode**, an AI-native desktop editor on Tauri + React + Rust
