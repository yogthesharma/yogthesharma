5+ years shipping complex React / Next.js apps, component libraries, dashboards, and performance-critical UIs. I care about reusable systems, clean architecture, and interfaces that stay fast under real load.

**Signal highlights**
- Cut feature rollout time by **~30%** with shared React + TypeScript patterns across onboarding, payments, and documents at Atlys

- Building **lcode**, treating AI as platform infrastructure (capability registry, event bus, tools), not a bolted-on chatbot
